# FinPlan — AFPK 재무설계 ICT 프로토타입

29세 가상 고객 김민준의 비상자금·대출상환·주거자금 목표를 비교하는 React 웹 MVP입니다.

## 실행
```bash
npm install
npm run dev
npm test
npm run build
```

## 기준 데이터
- 월 실수령액 2,800,000원
- 생활비 1,700,000원
- 학자금대출 잔액 6,000,000원, 연 2%, 약정상환 200,000원/월
- 신용대출 잔액 8,000,000원, 연 7%, 약정상환 500,000원/월
- 금융자산 4,000,000원
- 월 잉여자금 400,000원, 순자산 -10,000,000원

모든 대출 조건은 테스트용 가정입니다. 실제 금융기관의 일할 이자·상환일·수수료·변동금리는 반영하지 않습니다. 실제 금융 계좌와 연동하지 않는 데모입니다.
