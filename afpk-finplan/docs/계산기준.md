# 계산 기준 v0.1

- 월 실수령액 2,800,000원
- 생활비 1,700,000원(550,000+400,000+150,000+100,000+500,000)
- 학자금대출 6,000,000원, 연 2%, 약정상환 200,000원/월
- 신용대출 8,000,000원, 연 7%, 약정상환 500,000원/월
- 금융자산 4,000,000원
- 월 잉여자금 = 2,800,000 - 1,700,000 - 200,000 - 500,000 = 400,000원
- 순자산 = 4,000,000 - 6,000,000 - 8,000,000 = -10,000,000원

월 이자 = 기초 잔액 × 연이율 / 12. 월 상환액은 약정액+추가상환액과 잔액+이자 중 작은 값. 기말 잔액은 max(0, 기초잔액+이자-상환액).

대안 A 비상자금 우선, B 신용대출 우선, C 병행형, D 주거자금 우선. 초기 버전은 대출 완납 후 해방되는 상환액을 자동 재배분하지 않으며, 주거자금 목표 시점은 각 대안의 단순 월 적립액으로만 계산합니다. 목표 간 상충관계를 드러내는 시제품이며, 제출 전 실제 계산 결과와 수식 검증이 필요합니다.

모든 조건은 가상 가정이며 실제 금융상품 조건이 아닙니다. 일할 이자·수수료·변동금리·세금·물가·투자수익은 반영하지 않습니다.
