# AI 활용 기술서 기록 양식

> 아래는 기록 구조다. 실제로 입력한 프롬프트·응답·검증 결과로 업데이트할 것. 실제 사용하지 않은 모델/버전/요금제 또는 수행하지 않은 검증을 기재하지 않는다.

## 1. 사용한 AI 도구
| 도구명 | 실제 모델·버전·요금제 | 사용 목적 |
|---|---|---|
| 실제 사용한 도구 기입 | 사용 내역 확인 후 기입 | 아이디어 정리·코드 보조·테스트 설계 등 |

## 2. AI 활용 내역
| 단계 | 실제 입력 프롬프트 | 응답 핵심 요약 | 직접 판단·수정 | 산출물 |
|---|---|---|---|---|
| 자료수집 | 실제 프롬프트 붙여넣기 | 응답 후 작성 | 가상 고객에게 필요한 항목만 선정 | 고객 데이터 명세 |
| 계산 로직 | 실제 프롬프트 붙여넣기 | 응답 후 작성 | 독립 계산 및 수식 검증 | 계산 엔진 |
| 테스트 | 실제 프롬프트 붙여넣기 | 응답 후 작성 | 테스트 실행 후 결과 기록 | 테스트 결과표 |

## 3. 검증·수정 내역
| AI가 제시한 내용 | 검증 방법·출처 | 발견한 문제 | 최종 수정 |
|---|---|---|---|
| 응답 후 기입 | 스프레드시트·공식 자료·테스트 | 실제 발견한 내용만 기입 | 수정한 내용 |

## 4. 종합 기술
- AI를 가장 유용하게 활용한 단계와 이유
- AI에 맡기지 않고 직접 판단한 부분과 이유
- 결과물의 품질을 높인 구체적 근거
- 남은 한계 및 향후 개선사항
